## Story

As a backend + frontend developer,
I want the test suite from stories 2.27 + 3.35 (Vitest + Playwright + axe + MSW + Testcontainers) extended to cover Epic 4's new surfaces — recovery service methods (resume/reconcile/rerun/pause/classify), reconciliation services (artifact drift + integration conflict), Compare Mode (backend + UI + mobile), operator UI (queue + dialog + classification) — under the **existing** CI tier structure,
so that Epic 4's new code paths have automated coverage and regressions are caught at the same CI gates as Epic 2 + Epic 3's surfaces.
